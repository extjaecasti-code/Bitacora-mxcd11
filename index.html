Conectar Gmail

La app usará OAuth de Google para leer y responder correos. Necesitas un Client ID de Google Cloud Console con la API de Gmail habilitada.

1. Ve a console.cloud.google.com
2. Crea un proyecto → APIs → Gmail API → Habilitar
3. Credenciales → OAuth 2.0 → Aplicación web
4. En "Orígenes JS autorizados" agrega la URL de esta app en Grid
5. Copia el Client ID aquí
